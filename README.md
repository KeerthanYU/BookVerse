# 📚 BookVerse — Online Book Store Website

<div align="center">

### *A Modern and Responsive Online Book Browsing Platform*

BookVerse is a clean, responsive, and user-friendly static website designed for book lovers to explore books across multiple categories such as Fiction, Biography, Self-Help, Technology, and Finance.

Built using **HTML5**, **CSS3**, and simple frontend design principles, this project focuses on delivering an elegant UI/UX experience suitable for academic presentations, beginner frontend practice, and portfolio showcasing.

</div>

---

# 🚀 Live Preview

> Open `index.html` in your browser  
or run a local server:

```bash
python -m http.server 8000
```

Then visit:

```bash
http://localhost:8000
```
